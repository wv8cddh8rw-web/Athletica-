ATHLETICA — SUIVI SPORTIF PERSONNEL

Contenu :
- index.html : application
- manifest.webmanifest : configuration PWA
- sw.js : cache hors ligne
- icon-192.png et icon-512.png : icônes

Démarrage rapide :
1. Décompresser le ZIP.
2. Pour tester, ouvrir index.html dans un navigateur moderne.
3. Les données sont conservées dans le stockage local du navigateur.
4. Utiliser Exporter pour sauvegarder régulièrement les données au format JSON.

Installation comme application :
Une PWA doit être servie depuis une adresse HTTPS (ou localhost). Déployer le dossier complet sur un hébergement statique HTTPS, puis ouvrir l'adresse sur iPhone dans Safari > Partager > Sur l'écran d'accueil.
Sur ordinateur/Android, utiliser l'option Installer l'application du navigateur si disponible.

Confidentialité :
Aucun compte ni serveur n'est utilisé dans cette version. Les données restent sur le navigateur et l'appareil où elles ont été saisies. Exporter une sauvegarde avant de changer d'appareil ou de navigateur.
